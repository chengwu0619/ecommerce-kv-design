# 合规与事实边界

主视觉是营销物料，写上去的每个数字都是承诺。规则只有一条：**用户提供的资料与已核验事实之外的内容，不写。**

平台规则、极限词清单、类目限制都会变。涉及具体平台审核口径时，优先查该平台官方最新规则；查不到就按保守口径处理，并在交付说明里标"未核验"。

## 绝对不能编造

- 价格、折扣、到手价条件、活动起止时间
- 销量、排名、好评率、复购率、买家数
- 检测报告编号、认证名称、专利号、奖项
- 功效、疗效、安全性结论、适用人群承诺
- 材质含量、产地、品牌授权关系

资料里没有的，要么去掉，要么写成客观属性（"玻璃瓶身"），不要升级成效果承诺（"保鲜 30 天"）。

## 中文极限词

主视觉上出现下列词一律去掉或改为可验证表述：

最、最佳、最好、最优、最强、第一、首个、唯一、顶级、极致、绝对、100%、全网最低、国家级、世界级、王牌、冠军、史无前例、绝无仅有、永久、终生、根治、治愈、零风险、包治、万能。

可替代写法：把绝对判断改成事实与条件——"通过 XX 检测（编号 XXX）"、"整机质保三年"、"单次充电续航 8 小时（实验室数据）"。

## 价格与活动

- 划线价（日常价）必须有依据（历史售价、吊牌价、官方指导价）；拿不到依据就不要出现划线价。
- "到手价"必须写清条件：券后、满减后、限时秒杀，条件文字与价格同时出现。
- 活动时间必须写明，且与后台活动一致；跨年要写年份，时区敏感的场景写清截止时刻（如 `10月31日 24:00`）。
- 赠品写数量与条件（"买 2 件赠 1 件"），不写"送完为止"这种无法核验的表述。

## 类目敏感

| 类目 | 需要额外注意 |
| --- | --- |
| 食品 / 保健 | 不得宣称功效、治疗、替代药物；"0 添加"需有依据 |
| 化妆品 / 个护 | 不得宣称医疗效果；成分与功效表述需与备案一致 |
| 医疗器械 / 健康 | 需资质与备案信息；不得夸大适用范围 |
| 母婴 / 儿童 | 年龄与安全警示必须准确；不得承诺绝对安全 |
| 电器 / 3C | 参数需与说明书一致；能效、认证必须有报告 |
| 跨境 | 目标市场语言与法规差异；避免 FDA approved、clinically proven 等无依据表述 |

## 平台差异（方向性提醒，需按最新规则核验）

- 淘宝 / 天猫：主图禁止牛皮癣式堆字、禁止非官方授权标识与夸大促销；白底主图与营销主图的用途不同。
- 京东：主图对文字面积与促销信息展示有额外限制。
- 拼多多：价格与促销表述必须与活动一致，注意"最低价"类比价表述风险。
- 抖音小店：短视频/直播封面与商品主图的规范不同，注意口播承诺与图片一致性。
- Amazon / Shopify / TikTok Shop：主图通常不允许促销文字与徽章，营销主视觉更适合放在 A+、Listing 副图或广告素材；避免无依据的认证与比较级最高级表述。

## 语言合规（英文版）

- 不用 `best`, `No.1`, `world's leading`, `guaranteed`, `100%` 等无依据表述。
- `FDA approved`、`clinically proven`、`medical grade` 之类必须有可核验依据。
- 保修与退换要写清期限与条件：`3-year warranty (registration required)` 而不是 `lifetime guarantee`。

## 处理方式

遇到不确定的表述，按顺序处理：

1. 能从用户资料里找到依据 → 保留，并在交付说明里记录出处。
2. 找不到依据 → 改成客观属性或删除。
3. 删除后信息不足 → 作为待确认项写入交付说明，不要用模糊词填空。

交付说明里的"待确认 / 风险"一节是硬性要求，不要省略。

## 图片素材授权

- 底图与配景只能用：客户自有拍摄 / 明确授权的图库素材 / 本 skill 生成（程序化或生图）。
- 带平台水印（小红书、抖音、站酷等）或来源不明的图片**不得作为交付底图**；更不得用涂抹、修复、内容感知填充等方式去水印——那是绕开署名，风险高于收益。
- 需要保留某张参考图的构图时，正确做法是**重新构图把它排除在画面外**（`build_scene_from_photo.py`）或改用等价的授权素材 / 生图重制，并在交付说明里写清素材来源与授权状态。
- 生图底图要在交付说明里注明"AI 生成"，并确认所用服务的商用条款。
