# 版式系统

以 1200×1500（4:5）为基准尺寸写数值；放大到 1800×2250 时用 `--scale 1.5`，坐标与字号按比例放大，不要手改数字。

## 网格与安全区

- 外边距 60px（画布宽的 5%）；品牌角标可贴 60px 边距，但不要进入更内侧。
- 竖向分三段：顶部品牌行（0–150）、中部主体区（150–950）、底部信息区（950–1500）。
- 底部信息带高度 130–170px，用于价格、活动时间、行动条；标题与副标题压在这条带上方。
- 产品主体占画布面积 35%–65%：实景氛围型偏小（35%–50%），白底信息型、大主体型偏大（50%–65%）。
- 主体重心放在 38%、62% 两条竖线附近，避免正中死板或整体偏沉。

## 三套骨架

### A. 实景氛围型 `scene-atmosphere`

适合家居、家具、灯具、大件；有场景实拍时效果最好。

骨架：顶部品牌字标 + 右上角标｜左右各 1–2 组编号标注（大号半透明数字 + 小标题 + 引导线 + “+”节点）｜右下圆形承诺徽章｜底部压暗后放系列名 + 超大主标题 + 一句副标题｜黄色/品牌色底栏放价格与活动时间。

要点：

- 场景底图必须先压暗再上字：顶部一层 0.40 的 scrim，底部叠两层（0→0.45、0.36→0.92），单层容易压不住浅色台面。
- 编号标注的引导线终点落在产品细节上，不要落在空白处；节点用小尺寸“+”圆点，颜色用品牌点缀色。
- 主标题用 150–200px 超大黑体，字号要敢于大，这是拉开与竞品差异的地方。

### B. 浅底信息型 `info-white`

适合玻璃器皿、餐具、小家电、收纳、日用消耗品；主打参数与材质。

骨架：浅灰/米白底｜左上大标题（2–3 行）｜材质芯片组（药丸 + “+”圆点）｜参数块（大数字 + 单位 + 小标签）｜细节微距小图｜项目符号卖点 2–3 条｜底部纯色带放价格与截止时间。

要点：

- 左文右商品：文字占左侧 45%，商品抠图占右侧 55%，两者不要互相压叠。
- 参数块最多 2 组，数字 90–110px，单位 30–36px，标签 26–30px；数字与单位必须同一基线。
- 卖点用圆点或短竖条做标记，每条不超过 14 字，最多 2 行。
- 底部色带用品牌强调色，价格最大、时间次之、附注最小。

### C. 大主体型 `hero-subject`

适合母婴、宠物、3C、清洁电器、大件；靠主体体量和关键参数说服。

骨架：浅暖渐变底 + 斜切色块｜左上小前缀 + 主标题｜药丸标签｜左侧竖条卖点 2 条｜大数字参数（承重/容量/续航等）｜右上深色信息卡（适用年龄/型号/容量）｜底部白条放品牌、价格、活动时间。

要点：

- 商品图尽量大，允许压住斜切色块的分界线，制造空间感。
- 信息卡是硬信息（年龄、型号、规格），不要放形容词。
- 左侧卖点 + 大数字参数形成两块视觉重量，参数块用最重的字重。

### D. 编辑纸感型 `editorial-paper`

适合高客单、设计感强、需要与详情页统一气质的商品；纸感底 + 高对比衬线标题的杂志排法。

骨架：纸纹底（`scripts/make_paper_base.py` 生成）｜顶部品牌图标 + 字标、右上角促销小字｜左上超大衬线主标题两行、第二行右移错位并用强调色｜商品居中压在细圆之上、带接触投影｜左列：产品名 + 细线下 2–3 条圆点卖点 + 细线下价格标签与大号数字 + 活动时间｜右列：竖排字距英文、圆环数据徽章、坐标十字圆、虚线刻度｜底部细线 + 左作品类小字 + 右下行动语加下划线。

要点：

- 强调色只用一个（本例铜色 `#B5773F`），品牌色只出现在 Logo，不要让强调色和商品撞色。
- 细线体系是这类风格的骨架：`width 1–2px`、透明度 20%–60%，颜色全部取自强调色或墨色。
- 标题用可变字重衬线（思源宋体 Black/Medium/Light 三档配合），中文 150–180px，拉丁按字数下调（约 110–120px）。
- 拉丁小字距标签必须配 `word_spacing`（2–3.5），否则字距会把词间距压扁成一长串。
- 商品用 `shadow` 图层加接触投影，纸面上才有重量感；投影要偏下、色偏暖。
- 竖排字距英文用「每字一行 + `\n`」实现，行距 1.25 左右，最多 12–15 行。
- 圆环徽章放硬信息（容量、年限、编号），不要放形容词。
- 适度的程序化装饰（细圆、十字坐标、虚线、圆点）是这类风格的识别度来源，但每加一个都要问"是否帮助理解商品"。

### E. 编辑场景型 `editorial-scene`

纸感型的场景化升级：把纸纹换成与商品配色呼应的渐变色，并加入配景。适合商品颜色明确、需要场景氛围又要保持调性的情况。

骨架：上行深、下行浅的呼应色渐变（`scripts/make_scene_base.py`）｜顶部品牌字标 + 右上促销小字｜左上两行超大衬线标题（第二行错位并换强调色）｜商品居中、占画面 60% 以上、落在石台上并带接触投影｜左列：产品名 + 细线 + 圆点卖点 + 细线 + 价格标签与大号数字 + 活动时间｜右列：竖排字距英文、圆环数据徽章｜底部左侧品牌锁壳（Logo + 字标）、右侧行动语加下划线，都落在浅色台面区。

要点：

- **渐变要跟商品配色对得上**：上行取商品深色部件（瓶盖/机身/包装），下行取浅色部件或台面，中间补一道暖色过渡。
- **文字安全带**：渐变在 78% 高度前保持深色，主标题、卖点、价格、时间全部落在深色区；最后 12% 是浅色台面，只放品牌行与行动语，改用深墨色。跨区混排一定出现读不清的字。
- **商品占比**：主体高度 ≥ 画面 1/2，60–66% 是"明显压住文字"的区间；左右两列 box 的右/左边缘要留在商品轮廓之内，避免被压住。
- **配景只铺下 1/3 与左右下角**：石台、亚麻、干果、枯枝放在台面上，不进文字列、不压商品轮廓。
- **强调色只用一个**：琥珀/铜色，用在第二行标题、细线、圆点、价格标签与行动语下划线；品牌色留在 Logo 与商品本体。
- 深色背景上不要放深色 Logo：把 Logo 移到浅色台面区（左下角品牌锁壳），顶部只留文字字标。

### F. 明亮场景型（浅雾 · 竹影水面）

场景型在浅底上的版本：浅雾背景 + 竹叶投影 + 竹枝 + 水磨石台座 + 水面倒影，深色文字全程可读。适合日用、个护、家居小件。

骨架（1200×1500 基准）：浅鼠尾草雾面渐变（`--palette mist`）｜竹叶投影落在左上墙面｜竹枝从右上角进入｜顶部左侧 Logo + 字标｜左上两行大标题（第二行换低饱和琥珀）｜左列：产品名、卖点、价格、活动时间｜商品中心约 0.70、底部落在 80% 高度线并坐在水磨石圆台上｜底部 1/5 是水面与台座配景带（倒影、涟漪、可选第二座台）｜左下角放促销角标。

要点：

- **浅底深字**：文字全用深墨绿（`#2E3A2C`），强调色用低饱和琥珀（`#B08A4A`），细线用墨色 25% 透明。
- **商品位置**：中心约 0.70（右 1/3），底部落在 80% 高度线；台座顶面中心要对齐这条线，商品才"站"在台上。
- **底部 1/5 是配景带**：水面、台座、倒影都在这一带，正文不要压进来（左下角可放促销角标）。
- **信息小字放大加粗**：正文 30–34px / Bold，标签 24–28px / Medium；浅底上的细字最容易读不清。
- **标题可被商品轻微遮挡**：被遮高度 ≤ 字符高度 1/4，且不能切断一个词（英文尤其容易在词中被切）。
- 水面倒影与竹叶投影都要低对比（透明度 15%–35%），否则抢文字。

### G. 摄影场景 · 侧置主体型 `scene-photo-side`

用真实/生图的摄影静物底图（棚拍墙、水台、石台）做出的成品级版面，最不容易"设计感过重"。

骨架（1200×1500）：摄影底图铺满｜顶部左侧 Logo + 字标｜左上两行大标题（第二行换琥珀色）｜左列自上而下：产品名、卖点、价格、活动时间｜商品中心 0.674（右 1/3）、底部落在 80% 高度线并站在台座上｜底部 1/5 是台座 + 水面 + 倒影｜左下角促销小字。

硬性数值（照抄即可，改版时也保持这套关系）：

| 项 | 数值 |
| --- | --- |
| 商品中心横向位置 | 0.674（右 1/3 区间） |
| 商品底部高度 | 0.80（= 底部留 1/5 配景带） |
| 商品高度占比 | 56–60% |
| 左列文字区右边缘 | ≤ x 620（不得进入商品轮廓） |
| 产品名 / 卖点 | 36px Bold / 34px Bold（拉丁 32 / 31） |
| 价格数字 / 标签 | 146px / 28px（拉丁 140 / 24） |
| 活动时间 | 27px Bold（拉丁 30） |

要点：

- 底图三条来源：`build_scene_from_photo.py`（自有/授权照片重构）、`make_scene_base.py`（程序化）、生图（`imagegen-scene-prompt.md`）。
- **商品站在水面或亮面石材上必须补倒影**（`make_reflection.py`），否则会浮在半空。
- 标题允许被商品轻微遮挡（≤ 字符高度 1/4），但拉丁词不能被切断到读不出：英文标题通常要缩到 92–98px 并左移。
- 浅底上的小标签用更深的琥珀（`#8F6B33`），`#B08A4A` 只留给大号标题与圆点。

### F. 编辑场景·浅调偏侧 `editorial-scene`（当前默认场景型）

浅调、留白大、商品偏侧的现代排版；适合香氛、个护、饮品、器物等轻调商品。

骨架：极浅薄荷/米白渐变 + 边缘重度虚化的枝叶（浅景深）｜顶部左侧品牌字标 + 右上促销小字｜对侧文字列：两行超大衬线标题（第二行换强调色）、产品名、细线、圆点卖点、细线、价格标签与大号数字、活动时间｜商品偏右（约 0.68）或偏左，略高于视觉中线，落在底部配景带的顶边上｜底部约 1/5 为配景带：缎面/织物 + 松枝 + 小果 + 干果｜右侧边缘竖排字距英文 + 一枚小色点。

要点：

- **商品偏侧**：中轴线上放商品会显得呆板，也浪费了另一侧的排版空间。偏侧后文字列可以放宽，标题可以更大。
- **底部 1/5 配景带**：配景带的高度用 `--band 0.21` 控制；商品底部要落在配景带顶边附近，才读成"摆在上面"。
- **浅底上的文字**：用深鼠尾草墨色（#2E3A2C 级）做主体文字，单一金色（#B08A4A 级）做强调；不要用纯黑，也不要多个彩色。
- **浅底上的商品**：象牙白商品压在浅米底上对比很弱，必须叠两层 `shadow`（宽而淡 + 窄而实）把它按在底面上。
- **虚化枝叶**：边缘枝叶用大半径模糊（20px 以上）+ 低不透明度，只出现在四边与角落，不能进文字列，否则文字立刻发脏。
- **允许的遮挡**：标题末字可被商品压住一小部分（≤ 字符高度 1/4），但要保证整句仍能读下来；正文、价格、时间不允许被压。

## 字号阶梯（1200×1500 基准）

| 层级 | 用途 | 字号 | 字重 |
| --- | --- | --- | --- |
| L1 | 主标题 / 系列名 | 150–200 | black / bold |
| L2 | 参数大数字 | 80–110 | bold |
| L3 | 价格 | 62–80 | bold |
| L4 | 副标题 | 36–44 | medium |
| L5 | 卖点正文 | 30–38 | regular |
| L6 | 参数标签 / 单位 / 活动时间 | 26–34 | regular / medium |
| L7 | 角标、脚注、免责说明 | 22–28 | regular |

层级总数不超过 4 级（用字重和颜色做次级区分）。同一画面里字号不要出现相邻 5px 以内的两级，视觉上分不开。

## 颜色

- 品牌主色 1 个 + 中性色 2 个 + 强调色 1 个（价格、行动条、节点）。
- 深色照片上：文字用纯白，并加 `shadow`（`#00000066`, offset [0,3], blur 8）。
- 浅底上：正文用 #2E2D2A 级别，标签用 #6B6A66 级别，不要用纯黑 + 纯灰的对撞。
- 价格与行动条用强调色，不要用主色，避免和品牌视觉抢注意力。
- 对比度：正文 ≥ 4.5:1，大标题和角标 ≥ 3:1。达不到就加 scrim，不要靠描边糊过去。

## 构件规范

- **编号标注**：数字 80–100px、半透明（60% 白），标题 32–36px；引导线 2px，末端小“+”节点 13–16px。
- **圆形徽章**：直径 200–240px，环形文字 28–32px，环内放质保/认证/产地等硬承诺词，不超过 10 个字。
- **芯片（chip）**：高度 60–70px，圆角全圆，字号 30–34px，多个芯片之间用“+”圆点分隔。
- **参数块**：大数字 + 单位 + 标签，两组之间可用 2px 竖线分隔。
- **价格三件套**：活动价最大；日常价同基线、加删除线、颜色降一级；活动时间与条件文案单独一行，字号最小。

## 品牌规范

- 拿到品牌规范就先按规范放 logo（位置、留白、最小尺寸）；没有规范时统一放左上或右上，留白不小于 logo 高度的 1 倍。
- logo 不拉伸、不重绘、不改色、不加描边和发光；只有单色场景可用官方提供的单色版。
- 品牌字标（文字形式）的字体、字距、大小写要与品牌一致；英文版不要自行改成全大写。

## 常见问题

- 文字压在商品关键细节上 → 移动文字块，或加深该处 scrim；不要缩小商品来腾位置。
- 信息太多 → 先砍到 1 个主标题 + ≤3 条卖点 + 1 组价格 + 1 行时间，其余进详情页。
- 中文标题超过 14 字 → 改成两句：主标题给价值，副标题给限定条件。
- 字号被压缩超过 40% → 说明盒子太小或文案太长，改文案或改骨架，别硬压。
