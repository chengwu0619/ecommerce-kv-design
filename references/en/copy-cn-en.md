# Bilingual CN/EN copy

Prices, promotion dates, and final-price conditions enter the copy only when the task actually involves a promotion, and they need a verified source; when there is no promotion, never add promotion fields just to fit a template.

## Character budgets by hierarchy

| Slot | Chinese | English | Note |
| --- | --- | --- | --- |
| Main headline | 6–14 characters | 3–6 words | One core value only |
| Series / prefix | 4–10 characters | 2–5 words | Series name, category word |
| Subtitle | 10–18 characters | 4–8 words | Qualifiers: size, material, occasion |
| Selling points | ≤14 characters each | ≤7 words each | Three at most |
| Specifications | value + ≤4-character label | value + ≤3-word label | Two blocks at most |
| Ring badge text | ≤10 characters | ≤20 characters | Hard commitments |
| Promotion dates | 10月1日–10月31日 | Oct 1–31, 2026 | Must match the backend |
| Price | ¥399 / 到手价 ¥359 | ¥399 / From ¥359 | Currency symbol follows platform convention |

When you exceed a budget, change the copy first rather than forcing it in by shrinking the type (compression beyond 40% triggers a script warning).

## Chinese rules

- Write value in the headline, not stacked adjectives: 「小空间也能拥有的收纳美学」 beats 「高端大气上档次」.
- Use half-width digits, with no space between a number and its unit (`700ml`, `4mm`, `22kg`), but add one half-width space for visual clearance when mixing Chinese and Latin.
- Keep prices uniform: `¥399`; a struck-through price and a promo price must appear together with a visible strikethrough.
- Write promotion dates as `10月1日–10月31日` with an en dash rather than a tilde; include the year across a year boundary.
- Coin no new words, avoid homophone puns, and never use a technical term that does not appear in the product material.
- Chinese headlines take no full stop; subtitles may.

## English rules

- Not a literal translation — rewrite it the way an English product page would read.
- Headlines in Title Case, body copy and selling points in Sentence case.
- Units and regional conventions: dates `Oct 1–31, 2026`, thousands separator `1,299`, units `22 kg` (space between number and unit).
- Currency: keep the original currency and symbol (`¥399`, `$59.9`, `€49`). Any conversion must use a rate or price the user supplied; never convert on your own.
- Avoid Chinglish:

| Literal Chinese phrasing | Recommended |
| --- | --- |
| 价值信息 (value information) | value information from source (omit when there is no source) |
| 一键折叠 (one-key folding, verified) | folds with one hand (only when verified) |
| 环保材料 (eco-friendly material, with evidence) | verified material description (eco claims need a source, otherwise omit) |
| 已核验销量 (verified sales volume) | Verified units sold (omit when there is no source) |
| 已核验促销 (verified promotion) | verified promotion details (dates and conditions required; never add your own) |
| 免安装 (no installation, verified) | no assembly required (only when verified) |

The glossary supplies localised phrasing only, never factual support; claims about the environment, stock, sales, function, promotions, or official status all need a corresponding source, and are omitted or rewritten into neutral, verified objective descriptions when unverified.

## Cross-edition consistency check

- Product name, specification, material, price, dates, and commitments must be the same fact in the Chinese and English editions.
- The English edition may not contain CJK characters or full-width punctuation; the Chinese edition must not keep leftover placeholder English capitals.
- Both editions share one skeleton: text block coordinates are identical, with box width and type size adjusted only where copy length genuinely requires it.
- English copy usually runs 1.5–2× longer than Chinese, so write English by working back from the width of the same block rather than hoping the auto-shrink will save it afterwards.
