# 中英双版文案

## 信息分层的字符预算

| 位置 | 中文 | 英文 | 说明 |
| --- | --- | --- | --- |
| 主标题 | 6–14 字 | 3–6 词 | 只讲一个核心价值 |
| 系列/前缀 | 4–10 字 | 2–5 词 | 系列名、品类词 |
| 副标题 | 10–18 字 | 4–8 词 | 限定条件：尺寸、材质、场景 |
| 卖点 | 每条 ≤14 字 | 每条 ≤7 词 | 最多 3 条 |
| 参数 | 数值 + ≤4 字标签 | 数值 + ≤3 词标签 | 最多 2 组 |
| 徽章环形文字 | ≤10 字 | ≤20 字符 | 硬承诺词 |
| 活动时间 | 10月1日–10月31日 | Oct 1–31, 2026 | 必须与后台一致 |
| 价格 | ¥399 / 到手价 ¥359 | ¥399 / From ¥359 | 币种符号跟平台惯例 |

超出预算时先改文案，不要靠缩字号硬塞（缩小超过 40% 会被脚本告警）。

## 中文规则

- 主标题写价值不写形容词堆叠：「小空间也能拥有的收纳美学」优于「高端大气上档次」。
- 数字用半角，单位跟数字之间不加空格（`700ml`、`4mm`、`22kg`），但中英混排时按视觉留白补一个半角空格。
- 价格格式统一：`¥399`；划线价与活动价必须同时出现并可见删除线。
- 活动时间写法：`10月1日–10月31日`，使用连接号而不是波浪号；跨年要写年份。
- 不用生造词、不用同音梗，不用未在商品资料里出现的技术名。
- 中文标题不要出现句号；副标题可以。

## 英文规则

- 不是直译，而是按英文商品页的表达重写。
- 主标题用 Title Case，正文与卖点用 Sentence case。
- 单位与地区惯例：日期 `Oct 1–31, 2026`、千分位 `1,299`、单位 `22 kg`（数字与单位间留空格）。
- 币种：保留原币种与符号（`¥399`、`$59.9`、`€49`）。要换币种必须按用户给的汇率或实价，不得自行折算。
- 避免中式英语：

| 直译 | 建议 |
| --- | --- |
| high cost performance | great value for money |
| one key folding | folds with one hand |
| environmental protection material | eco-friendly material |
| sold well | best-selling |
| limited time big promotion | limited-time offer / on sale now |
| no need to install | no assembly required |

## 双版一致性检查

- 商品名、规格、材质、价格、时间、承诺在中文版与英文版必须是同一事实。
- 英文版不得出现中文字符或全角标点；中文版不要残留占位英文大写。
- 两版共用同一骨架：文字块的坐标相同，只有文案长度引起必要的框宽/字号调整。
- 英文版字数通常比中文长 1.5–2 倍，写英文时按同一 block 的宽度反推字符数，不要写完再指望自动缩字号。
