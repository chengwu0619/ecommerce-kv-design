# 交付验收清单

## 先跑脚本

```bash
python scripts/verify_kv.py --cn outputs/KV-CN-4x5.png --en outputs/KV-EN-4x5.png \
    --spec-cn work/spec/kv-cn.json --spec-en work/spec/kv-en.json

# 甲方给了中英内容母本表时必跑
python scripts/check_copy.py --master work/brief/content-master.json \
    --spec-cn work/spec/kv-cn.json --spec-en work/spec/kv-en.json
```

退出码非 0 就必须返工。脚本检查：文件存在、PNG 格式、精确 4:5、最短边 ≥1000px、非纯色、每处文案区域都有笔迹、中英尺寸一致且不是同一张图。

`check_copy.py` 逐项核对内容母本：母本里每条信息是否都进了对应语言版本、英文版有没有中文残留。母本完整性是甲方硬要求时，必须 0 漏项。

## 然后逐条看图（脚本查不出的部分）

**规格**

- [ ] 中文版 1 张、英文版 1 张，文件名与规格一致
- [ ] 1200×1500（或按约定倍率放大），竖版 4:5
- [ ] 外边距 ≥60px，元素没有贴边或出血

**信息层级**

- [ ] 3 秒内能说出这张图在卖什么
- [ ] 主标题只承载一个核心价值，字号是全图最大
- [ ] 主标题/价格已放大到压得住画面；与商品交叠时被遮高度 ≤ 字符高度 1/4，关键词仍可辨认
- [ ] 行动语按需求决定：不需要时画面里彻底没有（文字层与下划线层都删掉）
- [ ] 支撑卖点 ≤3 条，每条不超过 2 行
- [ ] 信息层级 ≤4 级，价格和时间一眼可辨
- [ ] 没有为了塞信息而缩到读不清的字号
- [ ] 信息小字已放大加粗：正文 ≥30px、标签 ≥24px、字重 Bold/Medium（1200 宽基准）

**主体与画面**

- [ ] 商品主体高度 ≥ 画面 1/2（场景型建议 56–66%），是画面里最重的元素
- [ ] 商品站在台座/水面上时有接触投影；水面场景还要有倒影，不能悬空
- [ ] 商品不在中轴线上（靠左或靠右），且略高于视觉中线；文字列在商品对侧
- [ ] 底部配景带约占图高 1/5，商品读成"摆在配景上"，没有浮在半空
- [ ] 左右两列文字没有被商品轮廓压住（逐行核对文字块边缘）
- [ ] 商品完整、不畸形、关键结构没被裁
- [ ] 商品是视觉重心，面积与位置符合所选骨架
- [ ] 文字没有压在商品关键细节上
- [ ] 每处文字的背景对比度足够（正文 ≥4.5:1）
- [ ] 渐变背景上文字没有跨明暗区：浅色字全在深色区，深色字全在浅色台面区
- [ ] 底图无伪文字、无第三方水印、无平台角标

**品牌**

- [ ] logo 位置、比例、留白符合品牌规范，未拉伸或改色
- [ ] 品牌色、字体与规范一致
- [ ] 角标/徽章内容是已核验的硬承诺

**文案与事实**

- [ ] 内容母本逐项进入对应语言版本（0 漏项）
- [ ] 经用户确认删除的母本项已在母本 `waived` 里登记（`check_copy.py` 输出显示为「豁免」）
- [ ] 价格、划线价、到手价条件正确且前后一致
- [ ] 活动时间与后台一致，含年份或截止时刻
- [ ] 无错别字、无多余空格、无全角半角混用
- [ ] 无极限词、无编造的销量/认证/功效
- [ ] 英文版无中文残留、无中式英语、单位与日期格式本地化
- [ ] 中英两版的事实完全一致

**成对交付**

- [ ] 中英两版共用同一底图、同一骨架
- [ ] 两版并排看像同一套物料，而不是两张不同设计
- [ ] 英文版不是中文的逐字翻译

**文件**

- [ ] `outputs/` 下只有交付物，没有中间稿
- [ ] `work/spec/*.json` 是最终成图的对应规格
- [ ] 交付说明写清受众、主张、证据来源、价格与时间来源、待确认项

## 常见返工原因

| 现象 | 根因 | 处理 |
| --- | --- | --- |
| 成图上有豆腐块/方框 | 用了不含中文字形的字体 | 用 `cn` 字体族，或让 `pick_family` 自动切（脚本已内置） |
| 价格被划掉后看不清 | 删除线颜色与价格同色且过粗 | 删除线颜色降一级，厚度 ≤ 值字号 6% |
| 文案被裁掉 | box 太小，或锚点/连线超出画布 | 改 box、改锚点，或缩短文案 |
| 文字在浅色台面上读不清 | 只加了一层 scrim | 叠两层 scrim，或加深标记处 |
| 中英两版看起来不像一套 | 英文版改了骨架或底图 | 回到同一份坐标，只改文案 |
| 打印/放大后发虚 | 位图放大 | 用 `--scale` 重渲染，不要拉伸导出的 PNG |
| 审核被驳回 | 极限词、促销表述、价格依据缺失 | 按 `references/compliance-and-claims.md` 逐条清理 |
